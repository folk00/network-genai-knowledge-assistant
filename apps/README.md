# Apps

Runnable application entry points.

## `full_quiz_gui/`

Copy of the original PySide6 desktop app with the richer interface:

- DOCX quiz loading
- override CSV support
- wrong-answer tracking
- saved profiles
- AI Coach
- Deep Review
- Meta-Coach
- Concept Dossiers
- Nuclear Review
- Diagram generation
- Teach Zero / Catedra
- Claude/OpenAI provider switching
- RAG KB button wired to the ready retrieval/SDK layer

The app code is safe to publish, but do not publish real quiz DOCX files,
override files, generated reports, or screenshots showing protected content.
